## Your feature set at a glance

From Section 10.2 of the Master Technical Doc (12 May 2026):

> All learner features plus: team dashboard showing direct reports' progress, approval queue for incoming course requests, bulk approval interface, manager-summary weekly notification, team-level completion reports, performance metrics per direct report.

## What's new for you since v1

- **Bulk-approval UI** — approve multiple course requests in one action
- **Performance dashboard** with team metrics rolled up
- **Route-override capability** gated by tenant equality (audit-fix #4)

## What's still missing

- Predictive analytics on team training needs
- Automated nudge campaigns triggered by manager-defined criteria
