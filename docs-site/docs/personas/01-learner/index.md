# Learner — User Guide

!!! info "Who this guide is for"
    You are an **employee of Airpay** (or one of its tenants — ZEEA, or any of the ~80 organisation nodes under the Airpay tree) who uses Airpay Academy to consume training. This guide does not cover authoring or administration; if you have direct reports, see the [Manager guide](../02-manager/index.md) for additional features available to you.

## Your feature set at a glance

From Section 10.1 of the Master Technical Doc (12 May 2026):

> Dashboard with continue-learning widget and recommended courses; course catalogue with tenant filter; course detail page with prerequisites and assessment preview; SCORM and quiz attempt; classroom session enrolment and attendance view; learning path progress; skill radar and gap analysis; certificates of completion; profile edit with photo upload; my-requests page; my-orders page (cart-enabled tenants); notification preferences; multilingual selection.

## What's new for you since v1

- **Skill radar** &amp; gap analysis (Phase 4)
- **Photo upload** with automatic GD resize
- **Dark-mode toggle**
- **Mobile-optimised dashboard** that renders correctly at 590 px and below
- **Cart and order history** (only on cart-enabled tenants — currently the Public tenant)

## What's still missing — known gaps

- AI tutor for course questions (planned, not shipped)
- Social learning (peer comments on courses)
- Mobile-app offline mode for SCORM

These gaps are documented in the [platform roadmap](../../shared/changelog.md#planned).
