# L&amp;D Administrator — User Guide

!!! info "Who this guide is for"
    You are part of the **Learning &amp; Development team** at Airpay. You design courses, schedule classroom sessions, author learning paths, run compliance reports, and provision users. You inherit every feature available to a [Manager](../02-manager/index.md) plus the full administrative surface.

## Your feature set at a glance

From Section 10.3 of the Master Technical Doc (12 May 2026):

> All manager features plus: course creation, classroom session scheduling, learning path authoring, programme authoring, evaluation form authoring, notification rule creation, cohort management, organisation tree management, user provisioning via bulk CSV, compliance dashboard with audit export, recompletion rule management, gamification challenge creation, badge management.

## What's new for you since v1

- **Native single-user enrol modal** — no more drilling into BizLMS
- **Bulk-unenrol CSV** — symmetric with bulk-enrol
- **CSV export** from every datatable in the platform
- **YAML import-export** for role definitions

## What's still missing

- End-to-end SENTIENTIA pipeline (SOP → SCORM) — architected, not yet delivering
- Automated SOP-to-SCORM workflow
