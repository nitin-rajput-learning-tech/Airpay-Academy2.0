# Airpay Academy 2.0 — User Guides

Welcome to the user documentation for **Airpay Academy 2.0**, the in-house Learning &amp; Development platform of Airpay Payment Services Pvt. Ltd.

These guides are organised by **who you are**. Pick the persona below that matches your role, then follow the 8-section walkthrough inside that guide.

## Choose your guide

| Your role | Description | Approx. users |
|---|---|---|
| [Learner](personas/01-learner/index.md) | An employee of Airpay (or one of its tenants) who consumes training | ~2,762 |
| [Manager](personas/02-manager/index.md) | A people manager who approves training and tracks team progress | ~88 |
| [L&amp;D Administrator](personas/03-ld-administrator/index.md) | The team that authors courses, schedules classrooms, and runs reports | ~12 |
| [Course Author / SME](personas/04-course-author-sme/index.md) | A subject-matter expert who builds and maintains specific courses | shared |
| [Compliance Officer](personas/05-compliance-officer/index.md) | The owner of statutory training reporting (POSH, AML/KYC, DPDP, RBI) | shared |
| [Tenant Administrator](personas/06-tenant-administrator/index.md) | A category-scoped admin who manages one tenant's users and courses | ~88 |
| [Site Administrator](personas/07-site-administrator/index.md) | Super-admin with platform-wide access — break-glass only | 2 |
| [External Public Learner](personas/08-external-public-learner/index.md) | A paid external learner on the Public tenant (id 77) | ~676 |
| [API Consumer](personas/09-api-consumer/index.md) | A developer integrating HRMS / payroll / analytics via web service | shared |

User counts are from the production database snapshot of 12 May 2026 (see Section 1.3 of the master technical doc).

## Each guide follows the same 8-section structure

1. **Welcome** — who this guide is for, how to navigate
2. **Quick Start** — first login + dashboard tour + first 15 minutes
3. **Daily Operations** — the 80 % of tasks done weekly, step-by-step with screenshots
4. **Feature Reference** — every screen / button / setting documented, alphabetical
5. **Troubleshooting / FAQ** — common issues and recovery
6. **Glossary** — Moodle / BizLMS / Airpay terms (shared across personas)
7. **Changelog vs v1** — what's new compared to the old platform
8. **Contact &amp; Escalation** — how to reach L&amp;D, IT, or the super-admin
