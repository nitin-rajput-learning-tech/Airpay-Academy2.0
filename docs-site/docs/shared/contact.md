# Contact &amp; Escalation

If something in the platform isn't working, here's who to reach and how.

## By type of issue

### Functional / "how do I…" questions

**First port of call: the L&amp;D team mailbox** — `learning@airpay.co.in`

Response SLA: 1 business day for non-urgent, 4 hours for "I can't complete my compliance training".

### Technical bugs / platform errors

If the platform shows a red error message, a page won't load, or you're seeing data that doesn't belong to your tenant: this is a **technical incident**.

**Escalate via:** the L&amp;D team mailbox **plus** screenshot of the error + URL + browser type + persona you're logged in as.

The L&amp;D team will triage and escalate to platform engineering (Nitin Rajput, Head of L&amp;D) or to IT depending on severity.

### Security incidents

If you suspect any of:

- You can see another tenant's data
- You have access to admin pages you shouldn't
- Your account has been compromised
- A page is asking for credentials it shouldn't
- A third-party email claims to be from Airpay Academy and asks for sensitive data

**Stop using the platform immediately.** Email `security@airpay.co.in` and CC `learning@airpay.co.in` with a description and screenshot. The Head of L&amp;D is woken if needed.

### Compliance / audit questions

The Compliance Officer is the canonical owner. See the [Compliance Officer guide](../personas/05-compliance-officer/index.md).

### Billing / refund (external Public learners only)

See the [External Public Learner guide](../personas/08-external-public-learner/index.md) — refund self-service is built into the platform. If the self-service flow can't resolve your issue, contact `billing@airpay.co.in`.

## What to include in a support request

To help us resolve your issue quickly, please always include:

1. **Your username** (or email)
2. **Your persona** (Learner / Manager / L&amp;D Admin / etc.)
3. **The URL** of the page where the issue happened
4. **A screenshot** of the issue
5. **Browser + device** (e.g. "Chrome 121 on Windows 11 desktop")
6. **What you were trying to do** (one sentence)
7. **What happened instead** (one sentence)
