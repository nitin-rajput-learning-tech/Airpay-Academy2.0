### 2. Install Node 22 (LTS Jod) — for AMD rebuild

**Why:** Moodle 5.1.3+ Gruntfile pins Node engine to `>=22.11.0
<23.0.0-0`. We're on Node 24.14.1 which throws "Node version not
satisfied" at the first `grunt amd` invocation. Without grunt,
the 4 AMD modules using deprecated `core/modal_factory` (per P5
sweep) cannot be migrated.

**Steps:**

```powershell
# A. Install nvm-windows (Node Version Manager)
#    https://github.com/coreybutler/nvm-windows/releases
#    Get the latest nvm-setup.exe, run installer.

# B. Install Node 22
nvm install 22.18.0
nvm use 22.18.0

# C. Verify
node --version
# Expect: v22.x.x

# D. Test AMD rebuild
cd C:\xampp\htdocs\moodle5
node_modules\.bin\grunt amd
# Expect: AMD modules compile cleanly, no errors

# E. Switch back to Node 24 when not doing Moodle dev
nvm use 24.14.1
```

**Time: 15-20 min including nvm install.**
**Unblocks: P0 borrows #6 toast-a11y, #7 page_title, #8 deprecated
JS module + P5 deprecation migrations (4 modal_factory files).**
