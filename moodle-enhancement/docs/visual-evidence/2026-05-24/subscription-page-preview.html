Calendar subscription

Add your Sentientia LMS course deadlines, classroom sessions, and exam dates to Outlook, Google Calendar, or Apple Calendar. The link below is personal to you — keep it private.

🛡 Treat this URL like a password — anyone who has it can read your learning calendar. Use "Regenerate" below if you ever paste it somewhere by accident.

What's included

  • Course completion deadlines for every course you're enrolled in
  • Classroom (instructor-led training) session start and end times
  • Exam close-dates for the next 90 days

How to subscribe

📧 Outlook
Outlook on the web: Calendar ▶ Add calendar ▶ Subscribe from web ▶ paste the URL ▶ name it "Sentientia" ▶ Import. Desktop Outlook: File ▶ Account Settings ▶ Internet Calendars ▶ New ▶ paste the URL.
📅 Google
Google Calendar: Other calendars ▶ + ▶ From URL ▶ paste the URL ▶ Add calendar.
🍎 Apple
Apple Calendar (macOS): File ▶ New Calendar Subscription ▶ paste the URL ▶ Subscribe. iOS: Settings ▶ Calendar ▶ Accounts ▶ Add Account ▶ Other ▶ Add Subscribed Calendar.

Regenerate URL

Invalidates the current URL and issues a fresh one. You'll need to update the subscription in every calendar client you've already added.
