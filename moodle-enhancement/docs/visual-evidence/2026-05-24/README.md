## What changed

First release of `local_sentientia_calendar` — the outbound ICS
subscription URL per user. Surfaces (3):

1. **`/local/sentientia_calendar/index.php`** — user-facing page with
   the personal subscription URL, copy button, how-to instructions for
   Outlook / Google / Apple Calendar, and a Regenerate button.
2. **`/local/sentientia_calendar/regenerate.php`** — POST endpoint that
   revokes the user's current token and issues a new one.
3. **`/local/sentientia_calendar/ics.php?token=<…>`** — RFC 5545
   `text/calendar` feed endpoint fetched by calendar clients.

## Sample ICS feed (verification artefact)

Generated by running `ics_builder::build_for_user($userid)` against a
seeded scenario (one course deadline + one classroom session + one
exam close). Stored as `sample-feed.ics` in this directory — paste
into any calendar app to verify the RFC 5545 structure renders
correctly.

```
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//Sentientia LMS//Sentientia Calendar Sync 1.0//EN
CALSCALE:GREGORIAN
METHOD:PUBLISH
BEGIN:VTIMEZONE
TZID:Asia/Kolkata
…
BEGIN:VEVENT
UID:sentientia-course-42-user-123@sentientia.local
SUMMARY:[Course Deadline] AML Compliance 2026
DTSTART;VALUE=DATE:20260815
…
```

See `sample-feed.ics` for the full payload.
