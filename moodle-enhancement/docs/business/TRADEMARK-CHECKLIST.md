## Why this matters now

1. We are pitching "Sentientia LMS" to the founder/C-suite and plan to sell to customer #2.
   Using the name commercially before clearing it risks rebrand cost later.
2. **Moodle® is a registered trademark of Moodle Pty Ltd.** Their trademark policy restricts
   using "Moodle" in product names, domains and marketing for commercial services. Our own
   mark ("Sentientia") sidesteps this cleanly — but our collateral must say
   "built on Moodle™ technology"-style nominative use only, never "Sentientia Moodle" or
   a moodle-containing domain. ✅ Product Guide already follows this.

## Pre-filing checklist (in order)

- [ ] **1. Knock-out search (free, ~1 hour)** — IP India public search
      (tmrsearch.ipindia.gov.in) for "SENTIENTIA" + phonetic equivalents
      (SENTENTIA, SENTIENTIA, SENSHENTIA) in classes 9, 41, 42. Also: plain Google,
      MCA company-name search, GST portal, domain WHOIS.
      *Note: Latin "sententia" (= opinion/maxim) is a real word — check marks built on it too.*
- [ ] **2. Domain + handle audit** — sentientia.com / .in / .io / .ai availability;
      GitHub org; LinkedIn page. Grab what's free BEFORE any public pitch deck circulates.
- [ ] **3. Decide the applicant entity** — Airpay Payment Services Pvt Ltd vs a new product
      subsidiary. (Affects IP ownership story for investors and any future spin-out. The
      personal-backup-repo IP hedge in ADR-001 should be reconciled with whatever is chosen.)
- [ ] **4. Professional availability search** — trademark attorney full search + opinion
      (India first; Madrid Protocol for intl. later if customer #2 pipeline is foreign).
- [ ] **5. File TM-A in India** — classes below, word mark FIRST (broadest), logo/device
      mark second once the visual identity is final.
- [ ] **6. Use ™ immediately** on the Product Guide, decks, site — ™ needs no registration;
      ® only after grant.
- [ ] **7. Calendar the follow-ups** — examination report response window, opposition
      period, renewal (10 years in India).
