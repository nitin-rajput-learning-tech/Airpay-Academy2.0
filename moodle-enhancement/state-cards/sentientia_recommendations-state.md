## Mission

Tier 1 AI feature #5. Learners see the top 3-5 personalised course
recommendations on their dashboard, generated by Anthropic Claude from
their completion history, current skills, role, and per-tenant learning
patterns. Each recommendation carries a short rationale ("Why this?").

## Architecture decision

See [ADR-015](../docs/adr/ADR-015-ai-recommendations-engine.md). Highlights:

- **Model:** `claude-sonnet-4-6` default; configurable per batch.
- **Prompts:** Versioned in code (`prompt_builder::VERSION = 'v1'`).
- **Cost gating:** 4 layers (master flag + live-API flag + per-call
  [CONFIRM] + **per-customer** daily token cap — the correct unit for a
  fan-out feature).
- **Mock mode:** When `sentientia.recommendations.live_api` is OFF
  (default), the whole pipeline runs against a deterministic mock client.
- **Catalogue-bounded parser:** Claude cannot recommend a course that
  isn't in the candidate list — invented course IDs are dropped.
- **Multi-tenant:** Standard `customerid` + `costcenterid` conventions.
