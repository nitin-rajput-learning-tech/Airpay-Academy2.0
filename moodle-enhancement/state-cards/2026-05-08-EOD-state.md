## What the harnesses cover but UAT still needs

Smoke tests verify **business logic** (round-trip, gap math,
idempotency, escape rules). They do NOT verify:

- Visual rendering on real data volumes (3,500 users, 411 courses)
- Cross-tenant isolation under load
- Browser quirks (Chrome on Windows is what we test; Safari on Mac,
  Firefox, Edge not yet)
- Mobile viewport (590px breakpoint) on the new pages
- Dark-mode rendering of the new pages
- Tablist + ARIA announcements via real screen readers (VoiceOver,
  NVDA, JAWS) — axe-core only catches static violations
