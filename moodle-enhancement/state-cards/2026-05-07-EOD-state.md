### Bonus catches

1. **Mustache HTML-attribute escape gotcha (re-surfaced).** First Playwright
   run had 2 console errors `Expected property name or '}' in JSON at
   position 2`. Root cause: my view.php wrapped json_encode() in s() and
   the template uses `{{ }}` (double-brace HTML-escapes), causing
   double-escape. Fix: drop the s() wrapper. Verified by direct render
   test. Same bug pattern as G-04 — different mistake, same lesson.

2. **Schema upgrade FK-collides-with-index trap.** First upgrade attempt
   failed: "Key fk_user collides with index idx_user". Moodle XMLDB
   forbids both a FK and a separate index on the same column. Fixed by
   removing the explicit `idx_user` (the FK provides the index already).

3. **Datatable HTML cell rendering needs explicit `'format' => 'html'`.**
   Shared theme_airpayux/datatable text-escapes cells by default. Columns
   that emit pre-rendered HTML (e.g. an `<a>` link in the name column)
   must declare `'format' => 'html'` in the column def. Caught when WX-06
   couldn't find the program-row view link — the link was emitted but
   rendered as escaped text.

4. **Headless dynamic_form rendering edge case** (continued documentation).
   Modal-opens cases for forms that serialise large user/course lists
   server-side hit a Chrome+Moodle interaction that real browsers don't
   show. Functionality is covered by PHPUnit at the manager level —
   Playwright cases verify scaffolding only. Pattern applies to WX-01,
   WX-04, WX-05, WX-06.
